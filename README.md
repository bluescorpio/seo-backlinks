## 使用说明 / How to use

这些资源来自个人收集，**尚未逐项验证**。清单包含目录站、工具展示站、博客和其他网站；部分链接为首页，并非提交入口。

请先确认网站与你的内容相关，再查看其提交规则、收费情况和链接属性。清单不保证网站接受提交，也不保证获得外链、被搜索引擎收录或提升排名。

These resources were personally collected and **have not been individually verified**. They include directories, tool showcases, blogs, and other websites. Some links lead to homepages rather than submission forms.

Check relevance, submission rules, fees, and link attributes before using a resource. Inclusion does not guarantee acceptance, a backlink, search engine indexing, or improved rankings.

## 补充与纠错 / Contributions

欢迎通过 Issue 或 Pull Request 补充资源、更新提交入口或反馈失效链接。请提供名称、准确 URL，以及实际验证过的信息；收费情况和验证日期等字段将在核实后逐步补充。

Open an issue or pull request to suggest a resource, update a submission URL, or report a broken link. Include the name, exact URL, and information you have actually verified. Categories, fees, and verification dates can be added as resources are checked.
